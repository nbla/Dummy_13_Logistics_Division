---

Role

Large expedition, utility and modular field operations vehicle.

DV06 is based on the EXR 4x4 Outrider and represents one of the largest ground vehicle projects currently undertaken by Logistics Division.

Unlike vehicles based primarily on commercially complete platforms, DV06 is being constructed around a largely printed vehicle design.

Its intended configuration emphasizes:

- Trail capability
- Expedition work
- Utility operations
- Modular payloads
- Field support

The final operational specialization will develop as construction progresses.

Modular Payload System

DV06 is intended to support interchangeable rear payload modules.

The current plan is based on the mounting geometry of the original generator component included with the Outrider design.

A reusable module interface is planned:

DV06 Module Base

Development Method:

1. Import original generator 3MF
2. Retain approximately the lowest 3–5 mm
3. Preserve original screw holes and mating surfaces
4. Use resulting geometry as a common payload base
5. Build interchangeable modules above it

Before finalizing the system, the original generator installation will be evaluated to determine how easily payloads can actually be removed and exchanged.

Future Generator Project

A longer-term Logistics Division project may eventually provide DV06 with a genuinely functional miniature engine-driven generator.

Concept:

Small internal combustion model engine
→ mechanical generator
→ electrical regulation
→ usable electrical output

A model engine around 0.020 cu in / approximately 0.33 cc has been identified as an appealing size candidate.

The long-term objective is not merely a scale prop.

The generator should actually generate electricity.

This project remains highly experimental and is not required for DV06 completion.
